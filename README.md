# DroneAPP - Atualizações do Android

Este repositório contém apenas as atualizações feitas nos arquivos de configuração do Android:

1. **app/build.gradle**: Configurações atualizadas para o build Android
2. **gradle/wrapper/**: Arquivos atualizados do Gradle wrapper

## Alterações Principais

- Adicionado configurações lintOptions para evitar erros de verificação rigorosa
- Atualizado configurações de packaging para lidar com bibliotecas do SDK
- Configurado para melhor compatibilidade com as bibliotecas DJI

## Como Usar

Copie estes arquivos para o repositório principal DroneAPP mantendo a mesma estrutura de diretórios.
