# DroneAPP - Atualização para SDK DJI 5.13

Este repositório contém as atualizações necessárias para compatibilidade com o SDK 5.13 da DJI.

## Alterações Principais

1. Atualizado todos os imports para usar o namespace `dji.v5` ao invés de `dji.sdk` e `dji.common`
2. Modificada a inicialização do SDK para usar as novas classes e interfaces
3. Atualizada a estrutura de callback para compatibilidade com SDK 5.13
4. Atualizados os métodos auxiliares para obter instâncias de drone, câmera, etc.

## Compatibilidade

Esta atualização torna o aplicativo compatível especificamente com o drone DJI Mini Pro 4 usando SDK 5.13.
