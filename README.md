# DroneAPP - Atualizações do AI Controller

Este repositório contém apenas as atualizações feitas nos arquivos principais do controlador AI:

1. **ai_controller.py**: Implementação de controlador com modo mock para funcionar sem API OpenAI paga
2. **export/ai_controller.py**: Versão exportada com as mesmas implementações

## Alterações Principais

- Adicionado modo mock que não depende da API OpenAI paga
- Implementado processamento de comandos em linguagem natural via mock
- Implementado análise de imagens via mock
- Implementado geração de planos de missão via mock

## Como Usar

Copie estes arquivos para o repositório principal DroneAPP.
