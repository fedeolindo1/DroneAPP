# DroneAutoFly

Um aplicativo Android para operações autônomas de drone, especificamente projetado para navegar e escanear códigos de barras em papéis brancos A4 com recursos avançados de desvio de obstáculos.

## Recursos Principais

- Controle autônomo de drone DJI Mini Pro 4
- Escaneamento automático de códigos de barras
- Dashboard para análise de dados coletados
- Visualização animada do caminho de voo
- Detecção de obstáculos e navegação segura
- Integração com OpenAI para controle por linguagem natural

## Tecnologias Utilizadas

- Kotlin para desenvolvimento Android
- Integração com DJI SDK 5.13
- Algoritmos de navegação autônoma
- Processamento de imagem e escaneamento de códigos de barras
- Design de interface Android (UI/UX) com o estilo Scania

## Instalação

1. Clone este repositório
2. Abra o projeto no Android Studio
3. Conecte um dispositivo Android com o aplicativo DJI Fly instalado
4. Execute o aplicativo

## Configuração

Para usar o aplicativo, você precisará:

- Um drone DJI Mini Pro 4
- Um dispositivo Android compatível
- Chave de API do DJI SDK
- Chave de API da OpenAI (para o recurso de controle por IA)

## Como Utilizar

1. Conecte o dispositivo ao drone usando o aplicativo DJI Fly
2. Inicie o aplicativo DroneAutoFly
3. Configure os parâmetros da missão
4. Inicie a missão de escaneamento autônomo
